If you have an out of square opening this calculator will take the height, width and both diagonals and generate a diagram.

The diagonals can be measured with the tape measure in the corner of the window. This calculator is designed to use the difference between the diagonals. It will work as long as both diagonals are out by the same amount.

If the diagram has two or three raked edges try clicking the rotate button. The new diagram will still be the same shape, just drawn a different way.
